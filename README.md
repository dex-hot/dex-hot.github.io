# DexHOT project website

Project page for **DexHOT: Learning Hand–Object Configuration Transfer for Dexterous Manipulation**.

- [Website](https://dex-hot.github.io/)
- [Paper](https://arxiv.org/abs/2611.05119)
- [Research implementation](https://github.com/dex-hot/DexHOT-Code)

This repository contains the static website and the images, videos, and interactive visualization assets it uses. Research code and datasets are maintained separately.
