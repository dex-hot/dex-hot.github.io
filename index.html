Method

Learn local transfers.
Chain configuration subgoals.

A shared hand policy learns local transfers and reaches distant configurations through hierarchical chaining.

  1. 01

    Synthesize

    Build feasible hand–object configurations across diverse objects.

  2. 02

    Learn to transfer

    Train a shared policy with synthetic local-goal configuration pairs.

  3. 03

    Chain subgoals

    Compose long-horizon behavior using a planner or demonstrations.

Benchmark

DexHOTBench

120 objects. 1.2 million feasible configurations. A benchmark for hand–object configuration transfer.

Sample configurations. Evaluate transfer range.

d

One distance for the full hand–object configuration.

d is the mean Euclidean distance between 28 corresponding hand keypoints, measured in the object frame.

One metric jointly captures differences in:

  • Object position
  • Object orientation
  • Hand joint arrangement

Object position and orientation are relative to the wrist.
