At a glance

ANY GRASP → ANY GRASP

Core capability

Any feasible hand–object configuration can be the source, and another can be the target. DexHOT transfers between them with one frozen policy—without a fixed start grasp, a scripted endpoint, or task-specific retraining.

Arbitrary feasible source
Start from any validated, stable hand–object configuration—not a canonical initial grasp.
Arbitrary feasible target
Request another configuration from the object’s full validated pool—not a scripted endpoint.
Closed-loop tracking · 30 Hz
The hand policy continuously corrects finger motion toward the current configuration subgoal.
Subgoal replanning · 1 Hz
The planner refreshes intermediate configurations while the same frozen policy executes them.

01 / Motivation

Why object pose is not enough

The same scanner pose can be unusable when the hand blocks the sensing region or approaches an incompatible grasp.

Switch between the two executions to isolate the effect of specifying the hand–object relationship. The successful rollout preserves a task-compatible grasp while bringing the barcode into the scanner field.

02 / Method

Learn locally.
Transfer globally.

A single policy learns local configuration transfers and reaches more distant goals through hierarchical chaining.

  1. 01

    Synthesize

    Build feasible hand–object configurations across diverse objects.

  2. 02

    Learn to transfer

    Train a shared policy with synthetic local-goal configuration pairs.

  3. 03

    Chain subgoals

    Compose long-horizon behavior using a planner or demonstrations.
